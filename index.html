The Odin Project

The Odin Project is a free, open-source curriculum for becoming a web developer. It is project-based: you read, practice, then build something real and publish it. These are the topics I’ve been working through.

HTML

The structure of every web page.

  • Document structure and semantic elements
  • Links, images, lists and tables
  • Forms and input types
  • Accessibility basics

CSS

Styling and layout.

  • Selectors, specificity and the cascade
  • The box model
  • Flexbox and CSS Grid
  • Responsive design

JavaScript

Behavior and logic.

  • Variables, functions, loops, arrays
  • Objects and constructors
  • DOM manipulation and events
  • Factory functions and modules

Tools and workflow

How real projects are managed.

  • Git version control
  • GitHub repositories
  • Publishing with GitHub Pages
  • Debugging in browser dev tools
